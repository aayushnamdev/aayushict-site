# aayushict brand files

Open `aayushict-brand.pdf` for a quick look at everything in one file. Open `brand-guide.html` for the same guide in a browser. It shows everything visually: colours, fonts, sizes, the wordmark, building blocks and voice.

## Folder

| File | What it is |
|---|---|
| reference-site.html | The full approved reference website. Open in a browser and click around |
| BUILD-PLAN.md | The plan for Claude Code: routes, content, components, build order |
| aayushict-brand.pdf | Everything together: the guide plus all four designs, five long pages |
| brand-guide.html | The visual guide. Open in any browser |
| brand-schema.md | The same guide as plain text |
| tokens.css | Every colour, font and size as CSS variables |
| tokens.json | The same values as data, for Claude Code |
| pages/1-home-laptop.html | Home page, laptop |
| pages/2-home-phone.html | Home page, phone |
| pages/3-reading-page-laptop.html | Reading page with working toggle, slider and quiz. Home links here |
| pages/4-reading-page-phone.html | Same reading page on phone |
| pages/5-reading-page-text-specs.html | Reading page with every text style labelled |

## Notes

Pages need internet once to load the Google Fonts. Headings use Aptos, which shows on computers with Microsoft Office. Elsewhere you'll see Figtree, which is very close.

When you build with Claude Code, give it `BUILD-PLAN.md`, `brand-schema.md`, `tokens.css` and `reference-site.html`, and tell it to follow the plan and match the reference exactly.

In the PDF, headings show in Figtree because Aptos could not be embedded. On your computer with Office, the HTML pages show Aptos.
